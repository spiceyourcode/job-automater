# Accessibility notes — P12.4

WCAG 2.2 AA polish for auth, onboarding, dashboard, and kanban (UIUX §7 / §11).

## Shipped

| Item | Implementation |
|------|----------------|
| Skip link | App shell → `#main-content` |
| Theme | `next-themes` + labeled theme cycle (light/dark/system) |
| Icon buttons | `aria-label` on sidebar toggle, theme, notifications, keyboard help, mobile menu, profile remove actions |
| Keyboard shortcuts | `?` help; `g` then `d/j/p/a/s` navigation (ignored in inputs) |
| Focus | Dialogs use Radix focus trap; mobile nav Escape restores focus |
| Live regions | Pipeline stage moves announced via `aria-live="polite"` |
| Reduced motion | Landing animations disabled under `prefers-reduced-motion` |
| Touch targets | Nav / mobile links use min ~44px height |
