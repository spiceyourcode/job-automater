# Runbook — Closed Beta / Launch

## Exit criteria

- [ ] Staging E2E critical paths green  
- [ ] No OPEN P0 blockers  
- [ ] Hard gates enforced; validators in CI  
- [ ] Support / on-call contact known  
- [ ] Feature flags for risky surfaces  

## Launch checklist

1. Freeze scope; tag release.  
2. Deploy API then client (or coordinated).  
3. Verify health, auth, payments (if any), high-risk feature.  
4. Monitor errors / latency for first N hours.  
5. Communicate to beta users.
